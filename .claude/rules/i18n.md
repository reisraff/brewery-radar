# Internationalization (PT / EN / ES)

- Portuguese is the primary and default language; the choice is persisted in localStorage key `hop-radar-lang`.
- Static text uses `data-i18n="<key>"`; JS reads strings via `const t = TRANSLATIONS[currentLang]`.
- Every new key goes into all three of `TRANSLATIONS.pt`, `.en` and `.es`.
- Dataset column names and data labels stay in Portuguese; translate only UI text.
